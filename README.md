# Mando-a-language

Mandalorian Resource Pack

A compilation of Mandalorian-inspired language resources created by @Aethelix0 and featured on YouTube.

Windows & macOS TrueType Font
Font created by ErikStormtrooper.com

## Font Information

This Star Wars-inspired font is based on samples of the Mandalorian alphabet seen in the Episode II Visual Dictionary and menu screens from the 2004 DVD release of Star Wars. The font includes all English letters, numbers, and common punctuation marks, covering the characters typically available on a keyboard. Uppercase and lowercase letters are identical, and kerning has been enabled. For a complete character-to-key mapping, please refer to mandalorian_table.jpg.

## Accuracy of This Font

The primary source for this font is a menu screen from the 2004 DVD release of Star Wars. Unfortunately, several letters and numbers were not available in the source material, including m, p, q, v, x, z, 1, 2, and 0, and there was no punctuation present. To fill those gaps, the remaining characters were inspired by available reference material. Because of this, the font is estimated to be approximately 75% accurate.

## Is It Really Mandalorian?

Yes. In the Episode II Visual Dictionary, there is a small readout of the technical display from the Slave I. When compared with the alphabet used on the DVD, the similarity is clear.
